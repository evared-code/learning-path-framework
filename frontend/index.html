CSV File Format Requirements:

Your CSV file must contain the following columns (28 total):

Basic Information (4 columns):

  • ParticipantID - Unique identifier
  • Name - Full name
  • CurrentRole - Current position
  • TargetRole - Target position

SDLC Competency Levels (24 columns - 12 phases × 2):

For each phase, provide Current and Target values on a 0-3 scale:

  • Req_Current, Req_Target - Requirements Analysis
  • Design_Current, Design_Target - System Design & Architecture
  • Dev_Current, Dev_Target - Development/Coding
  • Test_Current, Test_Target - Testing & QA
  • Deploy_Current, Deploy_Target - Deployment & Release
  • Maint_Current, Maint_Target - Maintenance & Support
  • PSP_Current, PSP_Target - Process Planning (PSP)
  • TSP_Current, TSP_Target - Team Coordination (TSP)
  • Defect_Current, Defect_Target - Defect Management
  • Metric_Current, Metric_Target - Estimation & Metrics
  • Config_Current, Config_Target - Configuration Management
  • Doc_Current, Doc_Target - Documentation

Competency Scale: 0 = None, 1 = Beginner, 2 = Intermediate, 3 = Advanced
